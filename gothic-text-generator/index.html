Gothic text for Discord

Usernames, nicknames, roles, status

Discord accepts Mathematical Fraktur Unicode in display names, server nicknames, custom status, channel topics, and messages. Paste Bold Fraktur for clan tags — it holds weight in dark themes and small chat sizes.

Keep tags short. Long Fraktur lines are hard to scan in member lists. If a letter becomes a box on an older client, switch to Bold Sans on this page.

Gothic (classic Fraktur)

Bold Fraktur

Digits have no Fraktur forms in Unicode, so numbers stay plain (0–9). Five classic capitals (C, H, I, R, Z) come from older Letterlike Symbols — that is why they can look slightly different from the rest.

Gothic vs Blackletter vs Fraktur vs Old English

Searchers mix these labels. For this tool, they all point at blackletter-looking Unicode — but the history is not identical:

TermWhat it meansOn this site
BlackletterThe technical family: dense angular scripts from medieval Western Europe (Textura, Rotunda, Schwabacher, Fraktur).Umbrella term for the niche.
GothicEveryday English for blackletter. (In East Asia, “Gothic” often means sans-serif — not this page.)Primary search phrase for the generator.
FrakturGerman print blackletter with broken stroke endings; Unicode encodes two math alphabets (regular + bold).What the Gothic / Bold Fraktur styles actually output.
Old EnglishPopular American label for Textura-style display faces (tattoos, diplomas, jerseys). Not the Old English language, and not a separate Unicode alphabet.Same Fraktur paste as “gothic”; for installable faces use Medieval Generator.
Bottom line: if you searched gothic, blackletter, Fraktur, or Old English text to copy-paste, this page is the right job. If you need a TTF for InDesign, Canva, or a character sheet, switch to downloads.

Frequently Asked Questions

Is this a real font I can install?

No. These are Unicode characters that already look like blackletter — which is why you can paste them anywhere. For a TTF/OTF file, see free medieval font downloads.

Does Discord support gothic text?

Yes. Paste into usernames, nicknames, status, and chat. Prefer Bold Fraktur for small sizes — details in the Discord section.

Is gothic the same as Old English or Fraktur?

For copy-paste searches, usually yes. Technically Fraktur is what Unicode provides; Old English is a font-catalog label. Full breakdown in Gothic vs Blackletter vs Fraktur vs Old English.

Why do some letters show up as empty boxes?

Your device has no glyph for that code point. Styles marked high compatibility are safest. Grunge uses a CSS strikethrough on the page so Android does not hit the old combining-slash tofu bug; copied text is Bold Fraktur that pastes cleanly.

Why don't numbers change in most styles?

Unicode includes Fraktur letters but no Fraktur numerals. Monospace and Bold Sans include digit mappings.

Can I use this for a tattoo design?

Yes as a reference. Artists usually redraw lettering for the final stencil — see the tattoo tip above.

Is it free? Do you store my text?

Free, no signup, no limits. Everything runs in your browser.

What's the character limit?

500 characters. Blackletter reads best as a name, short phrase, or header.
