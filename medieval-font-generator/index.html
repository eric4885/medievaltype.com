Frequently Asked Questions

Is the preview the same as the downloaded file?

Yes. The preview uses the same TTF we ship in the zip. Rendering can still vary slightly by operating system hinting.

Can I use these fonts commercially?

Yes under SIL OFL 1.1. Keep the license file with redistributions. You cannot sell the font file alone as your own product.

Why also show Unicode?

Some users still need pasteable text for chat or a temporary mock. The primary product on this page is the installable font.
