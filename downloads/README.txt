About Windows Font Viewer sample text
-------------------------------------
On some Windows locales (including Chinese), the built-in Font Viewer shows a localized
sample sentence for EVERY Latin-script font. That sentence is chosen by the operating
system. It does NOT mean this font file contains Chinese (CJK) glyphs.

These MedievalType packs are Latin blackletter faces for English and other Latin text.
To verify: install the TTF, open Notepad or Word, choose the font, and type A-Z.

Suggested uses
--------------
- RPG / DnD character sheet titles
- LARP props and handouts (short labels)
- Certificates, diplomas, invitation titles
- Period UI and chapter headings
